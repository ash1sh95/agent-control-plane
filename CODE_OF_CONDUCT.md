# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. In short: be welcoming, be respectful of differing views and
experience, accept constructive feedback gracefully, and focus on what is
best for the community and the work.

Instances of abusive, harassing, or otherwise unacceptable behavior may be
reported to the project maintainer via the contact methods on the
maintainer's GitHub profile. All complaints will be reviewed and
investigated promptly and fairly, and the maintainer will respect the
privacy and security of the reporter of any incident.
